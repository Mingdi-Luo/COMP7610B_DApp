## 协作约定

- **分支**：每人在自己的分支开发（如 `feat/forge-page`），通过 PR 合并到 `main`。合约部分由成员 1 审，前端部分由成员 3 审。
- **接口**：改合约接口前先在群里说；改完在 `contracts/` 下运行 `npm run export-abi`，并把 `frontend/src/config/abi/` 一起提交。
- **本地开发**：全部在本地链上进行（见 README 的 Run locally）。MetaMask 只导入本地测试账户，绝不往这些地址转真钱。
- **重启本地链后**：选中 Hardhat Local 网络，在 MetaMask 的 设置 → 开发者工具 里点"删除活动和 nonce 数据"，每个测试账户都要做一次，否则会报 nonce 错误。旧版 MetaMask 的这个选项在 设置 → 高级 里。
- **私钥**：任何私钥、助记词都不能写进代码或 `.env`。部署到 Sepolia 用 Remix + MetaMask。
- **录视频前**：多开几包卡，确保手里有 3 张同级卡，能现场演示合成。
